# Projeto: LandingPage Mipo

Landing page de alta conversão para serviço de motoboy/entregas expressas em Balneário Camboriú e região.

---

## 🛠️ Aspectos Técnicos

- **Build Tool:** Vite
- **Linguagem:** TypeScript + Vanilla HTML/CSS
- **Estilização:** CSS / Tailwind CSS (a definir)
- **Hospedagem / Deploy:** Vercel / Netlify / GitHub Pages
- **Meta Tags & SEO:** Otimização para busca local (Balneário Camboriú e regiao) + Open Graph para redes sociais

---

## 🎯 Objetivo Principal

- Converter visitantes em contatos diretos no WhatsApp.
- Mensagem padrão preenchida no link do WhatsApp (ex: _"Olá! Gostaria de saber o preço de uma entrega com a Mipo..."_).

---

## 👥 Público-Alvo / Personas

1. **Empresas e Comércio Local:** Restaurantes, e-commerces, escritórios, farmácias e lojas que precisam de entregas recorrentes ou avulsas.
2. **Pessoas Físicas:** Necessidades pontuais de envio/retirada de documentos, chaves ou encomendas na região.

---

## 💡 Seções Pretendidas para a Página

1. **Hero Section:**
   - Headline clara sobre agilidade/segurança nas entregas.
   - Chamada para Ação (CTA) principal destacada ("Pedir Motoboy no WhatsApp").
2. **Diferenciais / Benefícios:**
   - Agilidade no atendimento.
   - Cobertura da região (Balneário Camboriú, Camboriú, Itajaí, etc.).
   - Segurança na entrega das mercadorias.
3. **Serviços Oferecidos:**
   - Entregas expressas (avulsas).
   - Contratos fixos/mensais para empresas.
   - Coleta e entrega de documentos/encomendas.
4. **Depoimentos / Prova Social:**
   - Avaliações de clientes ou métricas (ex: tempo médio de coleta).
5. **FAQ (Perguntas Frequentes):**
   - Áreas atendidas, formas de pagamento, como funciona a solicitação.
6. **Rodapé / Contato:**
   - Endereço físico (R. 1950, 321 - Centro, Balneário Camboriú - SC).
   - Horário de funcionamento.
   - Links úteis e redes sociais.
